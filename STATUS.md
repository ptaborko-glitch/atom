# Проект Atom — Статус разработки

**Дата:** 2 июня 2026

---

## 1. Цели проекта

Создать язык программирования Atom для написания нейросетей с простотой Python и скоростью C, а также собственную IDE, LLM и ИИ-агента.

---

## 2. Архитектура компилятора
Исходный код (.atom) → Лексер → Парсер → Семанализатор → HIR → Wasm Generator → .wat → .wasm → Запуск

text

## 3. Что уже реализовано

### 3.1. Python компилятор (прототип)
- ✅ Лексер, парсер, семантика, HIR, генератор Wasm
- ✅ Поддержка отступов (INDENT/DEDENT)
- ✅ Корректная генерация `br_if` (инверсия условия)

### 3.2. Self-hosting лексер (`lexer.atom`)
- ✅ Компилируется в `output.wasm`
- ✅ Распознаёт числа, идентификаторы, операторы, ключевые слова
- ✅ Возвращает `TOKEN_PLUS` для символа `+`
- ✅ Успешно разбирает код `x = 42 + 1`

### 3.3. Парсер на JavaScript (временный)
- ✅ Использует скомпилированный лексер
- ✅ Строит AST для выражений и присваиваний
- ✅ Поддерживает бинарные операции и унарный минус
